# FPGA-MusicPlayer-HPS-NIOS
Hybrid FPGA WAV music player on DE1-SoC. ARM Cortex-A9 (Linux) handles SD card and metadata parsing; NIOS II soft-core manages MMIO, button interrupts, and playback control. Features 3 digital audio filters, VGA metadata display, 7-seg time/filter indicators, and switch-controlled filtering.
